# Tanışma (Buluşmalar + Hayvanseverler) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 18+ sosyal onayın arkasında buluşmalar (grup sohbetli toplu mama turları) ve karşılıklı kabulle açılan bire bir sohbetli "Hayvanseverler" listesi; demo modunda baştan sona çalışır, Supabase'e kod değişmeden bağlanır.

**Architecture:** Kurallar sunucuda (Postgres RPC, RLS'te doğrudan erişim yok) ve aynısı `InMemoryBackend`'de. iOS'ta yeni `SocialRepository` + `ChatUpdates` protokolleri (MamaCore), `SupabaseBackend` ve demo uygulamaları, yeni `FeatureSocial` modülü (ViewModel'ler Linux'ta test edilir, SwiftUI `#if canImport(UIKit)`). Ekranlar AppFeature'dan Mahalle/Profil/Harita'ya enjekte edilir (feature modülleri birbirini import etmez).

**Tech Stack:** Swift 5.10 paket / iOS 17 SwiftUI, XCTest; Postgres 15 + PostGIS (supabase/postgres imajı), Deno (edge function saf mantığı), supabase-swift 2.x (Realtime).

**Spec:** `docs/superpowers/specs/2026-11-14-tanisma-design.md` (onaylı). Okumadan başlama; özellikle §5.5.

## Global Constraints

- Tüm sosyal RPC'ler **auth** (anon'a kapalı); tablolar RLS açık, `authenticated`/`anon` doğrudan erişemez.
- Sosyal onay yoksa (`adult_confirmed_at is null`) yazma RPC'leri `{status:'consent_required'}`; okuma RPC'leri (buluşma listesi/detayı hariç) boş döner.
- Buluşma: başlık 3–80, açıklama 0–600, başlangıç `now()+1 saat` … `now()+60 gün`, süre 30 dk – 8 saat (varsayılan 2 saat), kişi sınırı null veya 2–50, yer adı 1–80, kullanıcı başına günde en fazla 3 buluşma (İstanbul günü; plan kararı). Sohbet bitişten 24 saat sonra salt okunur, 30 gün sonra mesajlar silinir.
- Hayvanseverler: hakkımda 0–300, istek notu 0–200, günde 10 istek, reddedilen istek 30 gün bekleme; konum ≈1 km (`round(lat,2)`, `round(lng,2)`); bantlar `under_1km` (<1000 m), `1_3km` (<3000), `3_10km` (≤10000); 10 km dışı dönmez; kişiler haritada asla pin değil.
- İlgi etiketleri (sabit): `cats, dogs, birds, neutering, fostering, vet_transport, food_donation, photography`.
- Sohbet: yalnızca metin 1–1000, küfür filtresi (`private.contains_profanity` / `ContentFilter`), sohbet başına dakikada 20, kullanıcı başına günde 500 mesaj; 3 farklı rapor → `moderation_state = 'pending'`.
- Engelleme iki yönlü (`private.blocked_between`); kişisel sosyal veri hesap silinince cascade; düzenlenen gelecek buluşmalar silmede iptal bildirimiyle silinir.
- Metinler TR kaynak + EN çeviri (`scripts/l10n/en.json`, `python3 scripts/extract_strings.py --check` 0 eksik). Ton: iş ve hayvan merkezli, flört çağrışımı yok.
- Komutlar: Swift `cd ios/MamaKit && swift test`; SQL `bash supabase/tests/run.sh [dosya]` (bu Mac'te Colima + `PATH="/opt/homebrew/opt/libpq/bin:$PATH"`, `docs/YOL_HARITASI.md` §7); Deno `deno test supabase/functions/_shared/`; app `cd ios && xcodegen generate && xcodebuild … build`.
